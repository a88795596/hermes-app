# 保存收到的附件

## 意图

让用户把聊天和收件箱中收到的图片、视频和其他附件保存到手机可见的持久位置。现有下载缓存只供 App 预览，系统可以清理。

## 方案

可选方案是全部通过系统文件夹选择器保存，或全部经分享面板保存。前者无法直接进入相册，后者无法保证用户实际保存文件。本次采用图片和视频优先保存到相册、其他附件选择系统文件夹的方案。相册权限被拒或格式不被接受时，改由用户选择文件夹。

## 约束与行为

- 仅对有服务端附件 ID 的文件提供保存；已发送的附件原本来自手机，消息记录里没有可重新下载的 ID。
- 沿用已配对设备的鉴权下载、大小限制和完整性校验。保存文件不能只是缓存目录的路径。
- 用户取消文件夹选择时保持安静；下载、权限或写入失败时在附件旁显示中文提示，并允许重试。
- 保留原文件名；同名文件生成带序号的新名字，不覆盖已有文件。
- Web 版使用浏览器下载。新增相册原生模块后需重新编译 iOS、Android 包；本次不发布 OTA。
