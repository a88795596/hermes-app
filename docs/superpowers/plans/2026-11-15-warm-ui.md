# Warm UI Implementation Plan

> **For agentic workers:** Use the approved warm design references and the task briefs in `.data/warm-ui/`. Execute independently owned page modules in parallel; integrate and review together.

**Goal:** Rebuild every Hermes mobile business page and its existing detail, form and sheet states to match the approved 57-screen warm design set while preserving all functional behavior.

**Architecture:** Keep Expo Router and the existing workspace / transport / management logic. Update the existing theme and reusable primitives, give management pages a shared fixed header with a scrollable body, and refactor page compositions in their owning modules. No Hermes Agent source changes or new UI dependencies.

**Tech Stack:** Expo 58, React Native 0.88, React 19, TypeScript, existing Expo Symbols / Reanimated / Safe Area libraries.

**Spec:** `output/ui-redesign-2026-11-15/DESIGN.md`, `COVERAGE.md`, `manifest.json`, and the 57 PNG files in `generated/`. The user explicitly approved implementing this design set on 2026-11-15.

## Global Constraints

- Hermes Agent 源码保持原版。通过 Hermes 原生接口、配置或插件机制接入。
- Chinese UI; retain real data and operations, never hardcode screenshot fixture content.
- Light palette: background #F7F2EA, text #352820, primary #9C6548, tint #EBDDD0, divider #DDD0C2. Preserve system dark mode using warm dark equivalents.
- Match layout inside the phone, not the illustrated phone frame, camera island or status bar.
- Reuse native libraries and existing helpers. No new dependency for styling.
- Preserve pairing validation, pending drafts/attachments, API cancellation, idempotency, confirmations, accessibility, haptics, reduced motion and safe-area/keyboard behavior.
- Do not publish OTA, build/install to occupied devices, merge or push as part of this request.

## Shared management interfaces

Root will supply these from `apps/mobile/src/manage/shared.tsx`:

- `ManagementLayout({header, children}: {header: ReactNode; children: ReactNode})`: fixed header, keyboard-safe scroll body, warm page background.
- `ManagementHeader({title, onBack?, backLabel?}: {title: string; onBack?: () => void; backLabel?: string})`: Hermes title/profile and explicit parent back; absent onBack uses current route parent.
- `FormHeader({title, onCancel, onSave, saveLabel?, disabled?}: {title: string; onCancel: () => void; onSave: () => void; saveLabel?: string; disabled?: boolean})`: fixed cancel/title/save toolbar. Caller continues to own mutation and disabled/busy logic.

`ManagementScreen` in index.tsx will provide profile/back context, no longer own a ScrollView or outer page heading. Every screen branch must return `ManagementLayout`, including form/child branches. Existing Group/Row/EditField/Toggle/Confirm APIs remain compatible.
